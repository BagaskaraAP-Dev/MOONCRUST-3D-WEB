# 🌌 VibeCoder 3D — Interactive Web Universe

Web 3D interaktif modern yang dibangun menggunakan filosofi **Vibe Coding** bersama Antigravity (AGY).

## ✨ Fitur Utama
- **Mesin 3D Three.js Modern:** Rendering 60 FPS menggunakan WebGL dengan tone mapping sinematik.
- **Interaktif 360° (OrbitControls):** Putar, zoom in/out, dan geser objek 3D menggunakan sentuhan jari (HP) atau klik mouse (laptop).
- **HUD Glassmorphism:** Panel kontrol futuristik dengan efek kaca buram (*backdrop blur*).
- **Pengubah Bentuk Geometri (Morphing Shapes):**
  - Torus Knot (Cincin Simpul Kosmik)
  - Icosahedron (Polihedron Berlian 3D)
  - Cyber Sphere (Bola Inti Energi)
  - DNA Helix (Garis Spiral Ganda)
- **Tema Warna Dinamis (Vibe Modes):**
  - Cyan Neon
  - Sunset Purple
  - Emerald Gold
- **Partikel Luar Angkasa:** 1.800 bintang melayang di kedalaman 3D.
- **Efek Sentuh (Pulse Interaction):** Klik / ketuk objek di kanvas untuk memicu gelombang energi.

## 🚀 Cara Menjalankan

Buka terminal di folder `Vibecoder` dan jalankan:
```bash
npx serve -l 5173
```
Lalu buka browser di:
👉 `http://localhost:5173`
